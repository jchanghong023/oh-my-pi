# 1016 默认行为需求

## 1. 默认允许主目录会话

- 在用户主目录 `~` 启动 CLI 时，默认保留主目录作为会话工作目录，不自动切换到临时目录，也不要求传入 `--allow-home`。
- 保留显式 `--allow-home` 的既有用法；`--cwd` 仍优先使用指定目录。

## 2. 默认关闭 OTLP 导出

- 内置默认值为 `telemetry.otlpExportEnabled=false`；未显式配置时，即使设置了 `OTEL_*` 导出端点，也不导出跟踪、日志或指标。
- 已有配置与本次启动的显式配置仍优先于内置默认值；显式设置为 `true` 后，继续按上游的端点、协议和禁用开关规则启用导出，不重写用户配置。

## 验收

- 通过目录启动与遥测导出的定向回归，并从真实 CLI 入口验证：无 `--allow-home` 时留在主目录、显式 `--cwd` 生效、默认及显式关闭时不请求已配置的 OTLP 接收端、显式开启时实际导出跟踪。
- 实施与实际验证状态统一见[需求目录](README.md)。
