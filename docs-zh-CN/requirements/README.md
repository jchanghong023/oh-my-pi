# Fork 需求目录

本目录是本项目唯一固定需求目录。开发规则见仓库根 `AGENTS.md`；教程、翻译和研究资料用于说明与取证，不是另一个需求来源。

| 文档 | 权威范围 | 状态 |
| --- | --- | --- |
| [Fork 功能与默认值](fork.md) | 上游基线、个人模型与命令、文档检索、交互、分发、兼容性及验证体系 | 保留现有契约；本次未运行功能验证 |
| [多模型方案讨论](team.md) | `/team` 的行为、集成约束与验收 | 已实现；本次未运行验证 |

每条需求只有一个权威维护位置。修改已有功能时更新对应文档；新独立功能域可新增文档并更新本表，不按篇幅机械拆分。跨功能关系通过链接表达，索引不复制具体条款。目录或权威体系缺失时先补齐，再修改实现。

需求定义与实现、验证状态分开。代码和测试用于核对现状，不能据此删除待实现需求或降低验收条件。只有相应验证实际通过才可标记验收通过；本次迁移没有重新验证此前的功能或历史测试结论。
