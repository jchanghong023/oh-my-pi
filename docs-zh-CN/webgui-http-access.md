# WebGUI 内网／中转 HTTP 访问

WebGUI 使用普通 HTTP／WS，可从同一内网中的其他电脑直接访问，也可由手机经外部云中转访问；低带宽链路按首屏资源预算设计。它与 AIReq 原型共享浏览器兼容要求，但启动入口、监听端口及路由约定不同，不能把 AIReq 原型的 `4173`／`4174` 或 `OMP_AIREQ_BASE_PATH` 配置直接套给 WebGUI。

## 使用现有启动入口

在普通 OMP 会话中输入 `/webgui`，或运行独立命令：

```sh
omp webgui
```

使用终端实际输出的完整内网地址。WebGUI 由同一 OMP 进程持有 Web 服务，系统分配空闲端口，同实例的后续项目复用该端口。`http://10.242.201.214:4173/` 仅在该实例实际输出这个地址时才是正确入口，不能固定假设端口为 `4173`。

已选项目的地址可带 `?project=...`，应保留终端输出的查询参数。独立命令只启动服务和初始显示上下文，不自动打开项目或创建 Agent；在网页中显式打开项目、新建或继续会话后才进入原生工作。

## 页面路径与接口路径

WebGUI 的正式静态资源及接口位于本服务根路径。刷新允许的 SPA 页面深链接，例如 `http://机器IP:端口/xxx/xxx`，仍应读取根路径的静态资源；页面层级不能把脚本、样式或图标请求变成错误的 `/xxx/assets/...`。

业务连接沿用同源根路径：

| 用途 | 路径 |
| --- | --- |
| 工作区初始信息 | `/api/server-info` |
| 原生会话与项目信息 | `/api/omp/session-info`、`/api/omp/projects` |
| WebSocket RPC | `/ws`，普通 HTTP 页面连接同源 `ws://` |

这里的深链接不是“把整个 WebGUI 挂载在任意反向代理前缀下”。当前宿主仍校验本实例实际网卡地址、监听端口、同源 Origin 及实际对端；不信任代理转发头来扩大准入，不增加任意域名或端口重写。AIReq／Sketch 等原生应用的既有随机能力地址属于各自路由，应继续使用完整地址，不删除路径或复用成 WebGUI 的根入口。

## 普通 HTTP 下的浏览器能力

`http://localhost` 是浏览器的特殊例外，不代表 `http://内网IP` 也是安全上下文。因此前端不能仅以 localhost 启动成功作为内网兼容证据。

- ID 使用已有共享工具，不直接依赖 `crypto.randomUUID()`。
- 消息和路径的文字复制复用统一工具，在用户操作时兼容执行；失败必须保留失败反馈，不能提前显示已复制。
- WebGUI 不提供附件上传、文件上传或麦克风输入；不依赖 `crypto.subtle`、浏览器媒体权限或上传格式兼容。聊天仍支持纯文本、流式回复、工具结果与停止。
- 手机可能经约 3 MB/s 的外部云中转访问：首屏只加载聊天壳、项目／会话列表与当前会话，压缩后初始 JavaScript+CSS 目标 ≤ 1.5 MiB，单个懒加载块目标 ≤ 1 MiB；不预取全量语法、动态图标、PDF／Office／Mermaid／公式、市场／文件／Git／Workflow 资源。
- 外部云中转只透明转发 HTTP／WS，不要求 OMP 内置 Relay，不改变同源、Host、Origin 或对端准入，也不增加固定端口。

本次只做 WebGUI 源码与文档核对，按用户要求未启动、构建或截图 WebGUI，也未运行测试套件。AIReq 的内部浏览器检查不能代称 WebGUI、真实 OMP 业务、Firefox 或发行资源已经验收；WebGUI 前端变更仍需在后续正式构建中生成并携带对应静态资源。
