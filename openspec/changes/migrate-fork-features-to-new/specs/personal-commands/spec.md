# Spec Delta

## Purpose

让终端用户在当前会话中切换工作区和写入提醒、提出最小改动要求，并在内网环境中按需排查中文输入或附上离线画板图像。

## ADDED Requirements

### Requirement: 会话写入范围提醒

终端 MUST 提供 `/workspace` 来开关当前会话的写入范围提醒；提醒不授予权限，也不是写入拦截。

#### Scenario: 切换当前会话的提醒
- **WHEN** 用户在当前会话调用 `/workspace`
- **THEN** 此会话的写入范围提醒在开启与关闭之间切换，不改变其他会话和审批规则。

### Requirement: 会话工作树切换

`/wt <分支>` MUST 切换当前会话的工作树，不移动或丢弃任一工作树的本地变更。

#### Scenario: 工作树已存在或需要新建
- **WHEN** 用户指定已有工作树的分支，或指定尚无工作树的分支
- **THEN** 复用目标分支的现有树，或在源工作树旁创建；分支不存在时从当前提交创建。
- **AND** 两端的暂存、未暂存和未跟踪内容留在各自工作树。

### Requirement: 最小充分改动指令

终端 MUST 支持单独使用 `/minimal` 或附带任务使用，将最小充分改动与验证要求交给当前会话。

#### Scenario: 单独调用或附带任务
- **WHEN** 用户单独发送 `/minimal` 或随任务发送该命令
- **THEN** 会话收到该要求；附带的任务内容不会丢失。

### Requirement: 中文输入法排查

`/jchime` MUST 让当前会话的 AI 排查公司内网 Linux 终端的中文输入法，不经环境和权限确认不得尝试恢复操作。

#### Scenario: 排查并确认恢复
- **WHEN** 用户调用 `/jchime` 且目标环境和操作权限得到确认
- **THEN** AI 可以尝试恢复，是否恢复中文输入由用户在原窗口确认。

#### Scenario: 环境或权限未确认
- **WHEN** 用户调用 `/jchime`，但目标环境或操作权限尚未确认
- **THEN** AI 不尝试恢复操作。

### Requirement: 中文离线画板

`/sketch` MUST 打开无需联网的中文画板，支持手绘、粘贴图像、标注、调整画布、撤销、缩放和平移。

#### Scenario: 提交画布到草稿
- **WHEN** 用户编辑画布后按回车
- **THEN** 整张画布以 PNG 附到当前草稿，不自动发送。

#### Scenario: 公司内网手动打开
- **WHEN** 用户在公司内网模式下手动打开画板
- **THEN** 显示完整地址，在 Linux 尝试把该地址复制到剪贴板。
