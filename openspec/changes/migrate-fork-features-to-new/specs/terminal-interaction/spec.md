# Spec Delta

## Purpose

让终端用户在不中断当前会话的情况下切换显示密度，按需查看工具活动、历史记录和文件差异；默认布局兼顾窄终端及公司内网旧终端。

## ADDED Requirements

### Requirement: 四种显示模式

终端 MUST 提供四种可切换的显示模式，默认 `compact`，切换不改变当前对话或执行状态。

#### Scenario: 会话运行中切换显示
- **WHEN** 用户用 `/display` 选择 `detailed`、`concise`、`clean` 或 `compact`，或按 `Ctrl+Shift+O` 循环切换
- **THEN** 终端更新显示，当前请求、工具执行和对话保持原状。
- **AND** `clean` 和 `compact` 收起常规工具活动、结果图片、思考内容和自动后台完成通知。

### Requirement: 紧凑活动两行显示

`compact` MUST 在输入框上方分别显示模型状态和当前工作，各占一行。

#### Scenario: 准备调用到实际执行
- **WHEN** 模型等待、思考、回复或准备工具调用，或主会话暂停等待
- **THEN** 模型状态行反映阶段，暂停时显示实际等待对象；当前工作行显示工具动作及并发数，参数到达即更新预览，工具实际执行后才显示为运行中。

### Requirement: 最近工具输出预览

`compact` MUST 预览已派发且有文字输出的最新工具调用。最多显示五行工具输出，调用信息不计入这五行；全文仍可从原记录查看。

#### Scenario: 两处活动都结束
- **WHEN** 整体任务与底栏活动均结束
- **THEN** 最近输出预览保留三秒后收起，不影响原记录。

### Requirement: 本轮工具文件差异

`compact` MUST 显示本轮成功工具报告的文件差异，包括删除和重命名，默认折叠。

#### Scenario: 查看差异
- **WHEN** 用户按 `Ctrl+O` 展开本轮差异并滚动，随后按 `Esc`
- **THEN** 用户可查看所报告的差异，按 `Esc` 后回到折叠状态。

### Requirement: 树视图的工具搜索和详情

`/tree` MUST 支持按工具调用目的搜索并查看所选工具的实际记录。

#### Scenario: 搜索并打开工具记录
- **WHEN** 用户搜索工具目的、选中记录，然后按 `Alt+Enter` 或界面提示的替代键
- **THEN** 显示实际输入、结果和状态，`Shift+Up` 和 `Shift+Down` 滚动详情。

### Requirement: 输入框与底栏默认布局

普通和公司内网模式 MUST 默认使用可配置的圆角输入框，底栏默认左侧集中显示 Git、子代理、输出速度、缓存复用率、上下文用量和已用时间，右侧留空。

#### Scenario: 窄终端和同文件多种变更
- **WHEN** 终端变窄，或 Git 存在同时暂存和未暂存的同一文件
- **THEN** 框内底栏换行并优先保留右侧容量及路径末尾；Git 段用文本显示分支，同一文件仅计一次，无变更时省略计数。

### Requirement: 轮次用时和内置界面语言

终端 MUST 默认在对话中显示每轮用时，且允许在设置中关闭。内置界面 MUST 使用英文，欢迎区保留中文使用提示、新功能标题和字体提醒。

#### Scenario: 使用默认界面并关闭计时
- **WHEN** 用户启动默认配置的终端并完成一轮对话，随后关闭轮次用时
- **THEN** 内置界面和欢迎区按上述语言显示；关闭后不再显示后续轮次的用时。

### Requirement: 公司内网终端兼容行为

公司内网模式 MUST 提供旧终端兼容的 Unicode 预设，关闭 CLI 终端标题里的会话状态和重新规划时的自动改标题，且默认不与兼容终端交换程序运行状态。

#### Scenario: 内网启动与显式设置
- **WHEN** 公司内网模式启动 CLI，或用户显式设置主题、开启运行状态交换、手动命名会话
- **THEN** 默认预设使用旧终端较易显示的符号，显式主题优先；运行状态交换可开启，手动命名可用，重新规划不自动改标题。
