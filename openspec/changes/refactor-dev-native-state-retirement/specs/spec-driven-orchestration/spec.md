## REMOVED Requirements

### Requirement: 递归需求材料批准和交接一致

**Reason**: 本轮已确认的新 Dev 流程取代本条旧规则；继续保留会产生阶段、权限、资料归属或交付边界冲突。

**Migration**: 需求评审及文档确认使用完整同版文件，旧确认不用于新内容；不恢复开发批准集合或实施阶段，不迁移旧状态。

**Migration**: 业务 Agent 澄清 IR／SR，同版四份评审报告完整后由人工判断；不恢复旧人工裁决表单或自动评分门禁。

**Reason**: 本轮已确认的新 Dev 流程取代本条旧规则；继续保留会产生阶段、权限、资料归属或交付边界冲突。
