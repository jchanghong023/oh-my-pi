# personal-commands

## Purpose

fork 命令、关键词、会话契约及 [TUI 显示差异](#requirement-1-三种显示模式)；不另建调度器。

## Requirements

### Requirement: 原生 `/workspace` 工作区写入提醒

原生 TUI MUST 有会话级隐藏写入提醒；非沙箱／写保护。不增 `approvalMode`、CLI／ACP、审批／分析／拦截；工具／模型／审批／Plan 限制不变。

#### Scenario: 命令与独立会话状态
- **WHEN** `/workspace [消息]`／交付／派生／恢复
- **THEN** 默认关、会话独立持久；补全／状态可辨，与 Plan 共存。无消息只切换不启模型；有消息开启、原生提交一次，保留草稿／附件。
- **AND** 注入：开启时每批真实交付附一份当前提醒（含排队、steer、follow-up）；不改原文／草稿／历史编辑。synthetic follow-up、工具结果、子代理通知、无新输入的重试或压缩不造提交；重建可提醒。
- **AND** 目录：提醒列实际归一化范围：cwd 所属 Git 真根及子目录、`os.tmpdir()`、本会话 `local://` 实际目录。无 Git 明示仅准临时区，不兜底 cwd／home。其他仓库、`additionalDirectories` 不自动准；符号链接／平台归一化非写保护。
- **AND** 越界：可读；改／建／删／移／重命名前说明路径及操作并询问。授权仅对应路径和操作，不重问、不扩权／建程序级授权缓存。涵盖文件工具、Bash、Eval、导入模块、脚本、子进程。
- **AND** 派生：task／eval 和递归代理固定继承创建快照，warm／cold 续跑还原；不随各自 cwd 扩权，另准 OMP 分配的隔离树，各用其会话临时区。父切换仅影响后续输入／新代理；原隔离创建／合并／清理／权限／执行不变。
- **AND** 关闭：持久开关关即停；重建／续聊按持久开关滤旧活动提醒，保留用户历史；不保证抹除已见文本／摘要或不越界。

### Requirement: 原生 `/sketch` 离线画布

原生 TUI MUST 内置自包含的离线画布；源码及发行均无需扩展、公网或模型。不提供 GUI／ACP／RPC 入口或自动转发；远程用户手动 SSH 转发回环端口。

#### Scenario: 本地绘图与手动提交

- **WHEN** 打开画布
- **THEN** 满窗但不强制全屏，提供中文界面、绘图、粘贴图片、标注、笔刷设置、撤销、清空和调尺寸。支持光标中心缩放、原大小／适应窗口和无笔迹平移；视野变化不改变实际像素或导出尺寸。
- **AND** 浏览器 `Enter` 导出整张画布为 PNG 附件，保留原草稿和附件，不自动发送。兼容 Firefox 128，按本机隔离 Firefox 约定验证，不等同公司实机验收。

#### Scenario: offline 手动打开画布

- **WHEN** 按[统一真值](../fork-runtime/spec.md#requirement-安装与运行)处于 `OMP_OFFLINE`
- **THEN** 显示完整可访问地址，不启浏览器、不调用 Shell 别名或读取启动文件。Linux 成功取址后尝试复制完整回环地址，仅报尝试，失败仍可手抄。非 offline 和显式打开行为不变。

#### Scenario: 取消、隔离与本地服务清理

- **WHEN** 启动、提交、按 `Escape` 取消、失败或失去归属
- **THEN** 服务仅监听回环临时端口，每次使用独立能力 URL，拒跨源并限制载荷。提交、取消、失败或宿主销毁后关闭服务；取消保留草稿，迟到结果不串会话或视图。

### Requirement: 内置 Developer Test Agent

MUST 内置 `developer-test-agent`、五技能及 `/dt`、`/generate-dt-files`、`/generate-dt-dir`、`/incremental-dt`、`/cloud-dt-fix`；无旧宿主兼容层。

#### Scenario: 使用内置单元测试流程
- **WHEN** 显式调用
- **THEN** Python／Java／C/C++／Go 路由，生成／修复／覆盖率／断言审查／报告、覆盖率门禁、串行批任务。源码／发行内置文档／脚本／示例／二进制，不依赖插件／配置／项目 cwd。复用发现／展开／task／todo／ask／`skill://`。
- **AND** 代理／技能仅手动发现调用，不默认展示／选用／路由／注入。主代理澄清，headless 子代理不用交互工具。报告 `.codecovcli/cache`；无 `@baize/dtagent-plugin` 自动遥测，不改旧配置／记忆。

### Requirement: `/loopn` 顺序循环提示词

原生 TUI MUST 支持 `/loopn "x1" "x2" "x3"`（≥1 非空提示词）；无次数、间隔、条件、编辑器、暂停恢复；`/loop` 不变。

#### Scenario: 按序发送与回绕
- **WHEN** 启动／运行／停止
- **THEN** 空白须引用；空提示词／未闭引号拒启动。与 `/loop` 互斥，提示先停旧循环、不替换配置。首条立即原生提交，后等前轮及后台结清；末条回首（含单条）。沿用 Loop 调度／`loop.mode`；状态 `LoopN · 当前序号/总数`。
- **AND** `Esc` 原生中断本轮、再次 `/loopn` 或本轮报错即停并清列表／待发；普通输入不恢复，重启重给提示词。

### Requirement: 魔法关键词的内置命令

原生 TUI MUST 内置 `/ultrathink`、`/orchestrate`、`/workflowz`，不注册 ACP。

#### Scenario: 魔法关键词的内置命令的可观察行为
- **WHEN** 尾随任务
- **THEN** 接收并触发对应关键词。

### Requirement: JCH 命令

`/minimal [任务]` 与 `/jchime [故障现象]` MUST 复用提示词展开；非法输入不产生副作用。

#### Scenario: 最小变更提示

- **WHEN** 调用 `/minimal`
- **THEN** 单发或附任务原生提交最小充分变更和验证提示，不拦截测试或修改。

#### Scenario: 内网输入法恢复

- **WHEN** 调用 `/jchime`
- **THEN** 向内网小模型提交受限恢复任务，以 CentOS 7／GNOME Terminal／SSH X11（Exceed）／IBus 1.5.17／`libpinyin` 为默认背景，现场核实当前用户、显示、总线和 daemon，不沿用旧地址或 PID。
- **AND** 优先正常重启 IBus、恢复并验证引擎；失败再按实况修复当前显示的引擎、总线或进程，不盲重试。只有复核进程身份和启动参数后才可向该 PID 发 SIGTERM；确认退出且无接管实例后才可重建。不自动 SIGKILL，不另建 D-Bus。归属或权限不明时仅调查。
- **AND** 不提权、不批量杀进程、不安装或联网、不改持久配置、不关终端或重启客户端。分报服务状态和输入恢复；原故障窗口能否输入中文由用户确认，模拟或本机 Windows 验证不等同公司实机。

### Requirement: Grill Todo Markdown 任务清单

MUST 内置仅显式调用的 `/skill:jch-grill-todo`，复用 `jch-grill-me`，仅调整收尾并附清单规则，不改变原技能。只交付 Markdown，不执行任务、不启会话、不新增权限。

#### Scenario: 独立确认生成与覆盖

- **WHEN** 就绪问题已解决且用户确认一致
- **THEN** 先只读，另获在 cwd 生成固定 `.todo.md` 的许可；写前重查，存在则另获覆盖许可。拒绝即不写、不合并、不改名。重大决策变化后重新确认相关决策和生成许可。

#### Scenario: 完整 Markdown 清单与文件交付

- **WHEN** 已获生成及必要覆盖许可
- **THEN** 写出自包含目标、范围与权限、已定决策、核实过的来源、依赖、产出及最小充分验证。用同级 `##` 分组，首个普通 `- [ ]` 紧随标题；不嵌套、不把共享背景列作任务。每项可独立判断完成，显式写跨组依赖，当前组闭环后再进入下一组。
- **AND** 只有不可拆的实现、测试、文档和验收才合并；最终集成验收不替前项首次验证，也不阻塞其合理勾选。区分预期失败的回归、修复验证和整体验收，不提前勾或重复验证。写后核对结构、依赖和证据，报告路径与检查结果，不声称已实施或通过验收。

### Requirement: Codebase Design 内置技能

MUST 内置 `/skill:jch-codebase-design`，源 `mattpocock/skills` 的 `skills/engineering/codebase-design/`；仅改名，留正文／描述／Agent 元数据／材料／许可；沿用 JCH 打包、原生补全、`skill://` 授权。不设仅手调元数据／执行器／别名／新权限。

#### Scenario: 自动发现、原生调用与相对材料
- **WHEN** 会话／代理发现读取或显式调用
- **THEN** 按原生名称／上游描述自动发现、按需读包内文及相对 `DEEPENING.md`／`DESIGN-IT-TWICE.md`；子代理全新上下文，源码／发行同包；读取不授重构／测试／改动权。

### Requirement: `/wt` 会话工作树

`/wt` MUST 按目标提交及树状态切换，保留两端未提交内容。

#### Scenario: `/wt` 会话工作树的详细边界
- **WHEN** 指定分支
- **THEN** 目标即当前目录则不迁移、不清理；否则复用已有分支的工作树，或按该分支提交新建。仅分支不存在时从当前 `HEAD` 建分支。新树与源 checkout 根平级（含子目录调用），不受 `worktree.base`／`OMP_WORKTREE_DIR`，不置于 `~/.omp/wt`；路径冲突另选、不覆盖。
- **AND** 不切源分支、不搬未提交内容（含删除），保留两端暂存／未暂存／未跟踪改动；禁自动 stash／提交／reset／clean，忽略 `worktree.cleanSource`。仅新建树走原生 `post-checkout` 与技能／命令刷新；禁钩子约定不变。

### Requirement: 显式调用无模型网页保存命令

TUI／GUI MUST 支持 `/crawl <URL> [选项]` 和 `/crawl stop`。默认仅保存入口 Markdown，不调用模型或技能；缺 URL、未知选项或非法值报用法，不开始抓取。

#### Scenario: 保存单个页面

- **WHEN** 浏览器及目标目录获准使用
- **THEN** 逐页保存渲染后的正文，保留表格、列表及可回源链接，记录最终 URL，重名另取。不下载附件，不承诺无损归档。

| 选项 | 含义／默认 |
|---|---|
| `--recursive` | 发现同源导航 |
| `--output <目录>` | 会话 cwd 的 `tmp/` |
| `--concurrency <数量>` | 后台标签并发，默认 2 |
| `--max-pages <数量>` / `--max-depth <深度>` | 递归上限，默认不限；入口深度 0 |
| `--no-scroll` | 关闭默认逐屏滚动 |
| `--wait <秒数>` | 初载或展开全文后等待 DOM 的最短时间，默认 5 秒，可设 0–240 秒（含小数）；不逐屏重复 |

#### Scenario: 使用已登录浏览器

- **WHEN** 抓取页面
- **THEN** 沿用浏览器开关、`OMP_OFFLINE`、授权与目录限制。Browser Relay 复用登录态，仅用自有后台标签，不抢焦点或改动用户标签；缺少条件时报原因，不绕行。
- **AND** 只沿入口最终源发现导航（协议、主机、端口）；允许渲染与重定向跨源，不再从跨源结果发现站外导航。按最终 URL 去重，保留查询和 Hash 路由，仅折叠普通片段。
- **AND** 默认逐屏加载主文档和可见嵌套面板，等待正文稳定，不等事件流结束。只处理明确可见的全文控件，优先页内展开，链接仅在自有标签打开。禁止翻页、「加载更多」、业务点击或提交表单。未稳定、滚动无进展或全文未能读取时报告失败，不以摘要代替全文。

#### Scenario: 进度、取消与补全

- **WHEN** 抓取、失败或取消
- **THEN** 显示进度、最终结果及失败 URL／原因。单页失败不阻断其他页；取消或中断只释放本次标签，保留已存文件，重跑从入口起。TUI 补全命令、选项和本地输出目录，不用浏览器历史补 URL。

### Requirement: `/todoloop` 普通 Markdown 文件入口

原生 TUI MUST 支持 `/todoloop <路径> [--check]`。普通 Markdown 与 OpenSpec 变更清单使用同一解析规则，不自动运行 OpenSpec；路径按会话 cwd 解析，含空格须引用。

#### Scenario: 预检结果与执行前校验一致

- **WHEN** 用 `--check` 或启动执行
- **THEN** 使用同一校验；预检只读、无模型或派发，显示组、项及完成进度和首未完组／项。参数、读取或格式错误报实因，不猜路径、不修清单、不派发。

### Requirement: `/todoloop` 清单格式、分组及运行不变量

MUST 按原文顺序识别无编号、数字／点分数字、Superpowers Step 和 `[ ]`／`[x]`／`[X]`；数字全局、Step 组内不可重复。无编号项按全文件 checkbox 次序识别，不回填编号。

#### Scenario: 解析与保护清单

- **WHEN** 读清单、勾选或刷新进度
- **THEN** 支持 ATX／Setext 标题，保留原缩进、换行和编码标记。忽略代码及 HTML 注释内的示例，边界不明或空项时报错。首个实际 checkbox 前最近标题确定组级；同级标题分组、同名不合并、空组跳过，无前置标题则全文件一组。
- **AND** 仅允许当前组勾选未完项，或在项末追加不改变结构的执行／验证记录。不撤勾、不改既有正文、记录、顺序或归属。发现清单不可读或被违规改写即停派，结清后报因，不覆盖、不回滚。

### Requirement: `/todoloop` 组级串行派发与接续

MUST 由程序以清单为唯一持久进度，跳过全勾组，串行派发首未完组。逐项完成必要验证后才能勾选；勾选不等于独立代码验收。

#### Scenario: 逐项勾选与整组推进

- **WHEN** 本组工作实际结清且清单仍合法
- **THEN** 全勾才进下组；未完最多尝试三次，每次只做余项，不重做已勾项。耗尽时报告组、余项、实际次数和已知原因。重跑从实时清单接续、次数重算；全勾直接报完成，不调用模型或写入。

### Requirement: `/todoloop` 公共背景准备及实际结清

有余项的执行 MUST 先派一次只读 scout；仅查清单、明确引用及各组共用材料。OpenSpec 只读同变更相关材料，不自动实施、同步或归档。准备未有效结清不得派首组；不重派，且不计组尝试。

#### Scenario: 复用背景与停止

- **WHEN** 派发各组、接续或取消
- **THEN** 每组独立沿用原生 `task`、权限和缓存策略。复用本次必要背景与来源，组任务和前次结果只作增量，不带旧会话流水；派发前复核受前组影响的事实，不拿旧背景覆盖实时依赖。相同模型、工具和权限条件下复用稳定前缀，不把它当实际缓存命中证据。
- **AND** 取消、失权或会话结束立即停派；等自有工作实际结清，不冒报已停止、不回滚或影响其他会话。准备失败或必要材料不可用如实报告；组超时须结清才按清单和剩余次数决定。

#### Scenario: 同组逐项进度及终态

- **WHEN** 准备、执行或结清
- **THEN** 单一 TUI 状态显示文件、组／项进度、当前组／首未完项及尝试数；保留原生任务记录，区分完成、失败和停止。不把共享背景或派发材料写入主聊，不另做缓存或费用统计。

### Requirement: 原生 TUI 按房间号开房与加入

Windows／CentOS 7 原生 TUI MUST 提供 `/collab2 <房间号>`、`/collab2 join <房间号>`、`/collab2 stop`；无其他宿主入口。房号 1–64 ASCII 字母／数字／`-`／`_`，保留大小写及前导零，禁 `join`、`stop`。只开、回滚及停止本次自有原生主持房，不复用或替换 `/collab`。

#### Scenario: 主持人开房且两位同事可写加入
- **WHEN** 开房／加入
- **THEN** 主持获接纳并登记才报成功；来宾以原生可写握手进入同一会话，接收实时更新、发给主持 Agent，本地不运行 Agent。无工号／身份配置／登录／加入确认；占用、无房／已关、参数错分别报占用、不可用、用法，不覆盖／串房／回退提示或残留新房。

#### Scenario: 切换会话或登记期间结束
- **WHEN** 已协作、启动中或结束
- **THEN** 已主持／启动／作来宾时拒开或加入，不打断、替换或改绑；来宾用原生 `/leave`。`stop`、主持切换／退出只关闭本次自有房，不停 `/collab`；旧号失效，新会话不恢复。登记中停／撤，迟到登记不得报成功或关闭他房。
- **AND** 主持／来宾断线或知识库关房时结束相应客户端，不自动重连／补登；主持释房，旧号失效后可手动同号重开；来宾恢复原本地会话。

#### Scenario: 地址选择与异常输入
- **WHEN** `/collab2` 访问知识库
- **THEN** 直连 IP:9333：`OMP_COLLAB2_IP` 有效 IP 字面量优先；显式非法（URL、主机名、带端口等）报错，不请求／回退。未设时，`OMP_OFFLINE` 存在（非真值）用 `10.239.93.104:9333`，否则 `127.0.0.1:9333`。HTTP 登记／查询、WS 中继均无代理／TLS，原生帧仍加密；仅该命令可向该端点用远程明文 WS。
- **AND** 房号、密钥、写令牌不入持久输入历史、日志或诊断；房号及加入凭据不经旧发现发布。配置存在／知识库不可达不影响普通发送或其他命令；旧协作入口的回环 WS／远程 WSS、发现、代理、重连不变。

### Requirement: 1. 三种显示模式

OMP MUST 以 `/display [clean|compact|detailed]` 投影同一会话，默认 `compact`。无参命令和原可见性快捷键沿用原循环及保存／覆盖顺序；用户附件与识图配置独立。

#### Scenario: clean 与 compact 的显示差异

- **WHEN** 同会话、尺寸、配置、草稿和执行状态
- **THEN** clean 隐藏普通工具活动、结果图片及实际思考；compact 在 clean 上只增加活动区、最近 Output 和本轮 Diff，不另显示 `Working…` 行或逐次工具卡。detailed 沿用上游原序、全文、工具卡和 Diff，不强制展开。三档不显示自动后台完成状态行，仍可查原结果、诊断和工件。

### Requirement: 4. 显示投影边界

显示 MUST 不改变执行、原记录、模型上下文、权限、计时或协议；不重放消息或工具，也不遮挡输入、附件、审批、问答及选择。隐藏内容仍可由 detailed 或原全文入口访问；保存、复制及模型输入保留全文。

#### Scenario: 切换、恢复与压缩

- **WHEN** 切档、恢复会话、切换代理或压缩
- **THEN** 视口按当前档位重建，不串会话、不留旧档位内容。压缩中收到的子代理消息不在旧上下文提前消费，压缩后仍能继续投递。

### Requirement: offline 图标的旧终端兼容

MUST 仅在 `OMP_OFFLINE` 的 Unicode 预设通过共享符号层按表替换；显式主题优先。

#### Scenario: Unicode 界面保留可显示图标
- **WHEN** 命令补全、状态栏、扩展列表等取主题符号
- **THEN** 其余图标（含 `/fast` 的 `⚡`）、预设、图片不变；不探测 CentOS／缺字、装／包字体或自动换预设。

|符号键|位置|普通 Unicode → offline 默认|
|---|---|---|
|`cmd.eraser`|`/clear`|`🧹` → `×`|
|`cmd.extension`|`/extensions` 及扩展命令（含 `/autoresearch`）|`🧩` → `⊞`|
|`cmd.compass`|`/skillful`、`/guided-goal`|`🧭` → `→`|
|`cmd.stethoscope`|`/cleanse`|`🩺` → `✚`|
|`cmd.power`|`/quit`、`/q`|`⏻` → `■`|
|`icon.tokens`|底栏 Token 数|`🪙` → `#`|
|`icon.extensionHook`|扩展列表等 Hook 图标|`🪝` → `↪`|

### Requirement: 英文 TUI 界面与中文启动提示

ANSI／native 内置 TUI MUST 使用英文，优先沿用上游文案；欢迎区保留简体中文使用提示、「提示：」、「新功能」及 Nerd Font 提醒，不改变显隐或选择条件。

#### Scenario: 英文导航与界面文案
- **WHEN** 渲染内置 TUI
- **THEN** 只改界面文案，不改布局、交互、命令、配置或协议；不翻译用户、模型、工具或诊断原文，不影响非 TUI 或 `stt.language`。不新增语言设置或翻译框架。

### Requirement: 快捷键与状态栏

默认快捷键 MUST 保留：

| 快捷键 | 用途 |
|---|---|
| `Shift+Tab` | 切换计划模式 |
| `Ctrl+T` | 选择临时模型 |
| `Alt+P` | 显示或隐藏思考块 |
| `Alt+E` | 循环切换思考级别 |

#### Scenario: 默认分组与 Git 状态
- **WHEN** ANSI／native 渲染状态栏
- **THEN** `default` 左组不含 `vim`、`pr`、`cost`；`git` 与 `context_pct` 之间依次是 `subagents`、`token_rate`、`cache_hit`，`time_spent` 紧随 `context_pct`。右组默认留空；`subagents` 遵循配置组序，不强制移位或重复显示。
- **AND** Git 段用纯文本 `git main · Changes: 5`，无图标或 `*`、`+`、`?`。按原开关合计暂存、未暂存和未跟踪文件的并集，目录逐文件计数，忽略文件不计。零改动省略计数；分支未知或隐藏时用 `git Changes: 5`；两项皆无则隐藏该段。

#### Scenario: 窄终端下的输入与状态
- **WHEN** 终端变窄
- **THEN** 盒式输入底栏 MUST 随宽度折行，无适用提示时不占常驻帮助行；嵌入式上下文用量保持右对齐，路径按实际空间截断并保留尾部。

### Requirement: 全部工具的显示投影覆盖

当前档位 MUST 一致处理内置、扩展、MCP 和设备工具。活动可用已知工具名、动作和目标；参数流不是正在执行，工具返回不等于后台任务成功。detailed 的 Web Search 保留全文，不影响 CLI。

#### Scenario: 流式参数不完整

- **WHEN** compact 收到部分参数、缺字段或字段无效
- **THEN** 每次调用只显示一行，清理后按实宽截断，保留已知身份和意图；逐步更新，不伪造动作、不吞错误、不溢出。

### Requirement: 受限高度下补全选中项可见

ANSI 补全 MUST 优先保光标，菜单随余高及选中项滚动并接受所见。

#### Scenario: 三行或四行终端导航到末尾候选
- **WHEN** ANSI 可用高 3／4 行、至少三个候选，用方向键选末项
- **THEN** 无空间走原非菜单路径，恢复高度保原键位及所见选择。不移输入、不丢正文／光标／草稿／候选、不加设置、不重放或误执行 slash；native 保原受限选择，无不可见选中。

### Requirement: 多行输入的输入法安全布局

`tui.imeSafeCursor` 开且框聚焦用硬件光标时，带侧框非末行的光标若在文本末尾、无选区渲染，MUST 省右框，保左框及文本；否则原框。

#### Scenario: 光标在非末行末尾
- **WHEN** 满足上述条件
- **THEN** 未出现预编辑也生效；末行、其他区域、原文不变。

### Requirement: 紧凑模式显示本轮工具原始 Diff

compact MUST 在输入上显示本会话本轮成功工具产生的原始 Diff，含原生删除／重命名。不从 Git、快照、参数或历史推算，不合并同文件或把还原抵消，不入历史；下次用户请求或独立运行清空。

#### Scenario: 查看 Diff

- **WHEN** 有可显示的 Diff
- **THEN** 默认折叠；工具详情键（默认 `Ctrl+O`）展开，支持滚动，`Esc` 收起；无可展开项回退 TodoLoop。Output 仅去除同调用同文件已表达的成功回执及重复行，保留诊断、失败和未展示文件。

### Requirement: 固定两行活动区

compact MUST 固定显示模型和 Agent 两行，不写历史。模型区区分等待、思考、回复、准备调用；Agent 区显示实际运行的动作及并发数，主会话暂停时显示实际等待对象。完成或失效即撤，勿从历史或其他会话恢复旧状态。

#### Scenario: 窄屏、动效与等待

- **WHEN** 动作、布局或等待状态变化
- **THEN** 优先保工具身份和可辨路径／命令；ANSI／native 复用上游布局及活动动效，遵守减少动态效果。停止等待不取消后台任务，不另建状态、调度或跟踪。

### Requirement: 三档共享转录导航与输入布局

三档 MUST 复用原生转录布局、滚动归档及焦点。

#### Scenario: 转录或终端尺寸变化

- **WHEN** 正文、底部区域或终端尺寸变化
- **THEN** 按实际可见高度占位；高度不足时先保草稿光标和审批／问答。验收见[最小必要验证](../fork-maintenance/spec.md#requirement-compact-的最小必要验证边界)。

### Requirement: 紧凑模式的最近工具只读输出预览

compact MUST 在活动上方用最多六行展示最近合格的真实文本 Output：一行调用信息和最多五行输出。只读，不替代全文或工件；空间不足优先保输入。

#### Scenario: 最近有输出按派发顺序而非到达顺序选择

- **WHEN** 多个调用更新
- **THEN** 选已派发且有合格输出的最新调用；旧调用迟到不抢占。无真实文本、仅参数／图片、去重后为空或独立 TODO 均不是合格来源。优先保原诊断，不混合调用或把任务快照当作日志。

#### Scenario: 运行期间保留且停止后计时

- **WHEN** 整体任务仍运行，或底栏仍运行
- **THEN** 保持预览更新；异步工具返回不等于后台结束，服务或交互 PTY 则按启动调用自身终态。整体任务与底栏均结束后保留三秒；新输出、缩放或切档不延长。新合格源可替换，关窗不取消任务、不回退旧源或接受迟到更新重开。恢复只用当前会话未过期的事实。

### Requirement: `/tree` 工具意图与所选行内详情

ANSI／native `/tree` 的 `toolResult` MUST 将本调用非空白字符串 `i` 前置于原工具名／参数摘要，支持搜索；用户／助手行不变。

#### Scenario: 工具结果行使用自身调用意图
- **WHEN** 无有效 `i`
- **THEN** 保原摘要，不借其他调用或结果正文。

#### Scenario: 仅展开当前所选工具行
- **WHEN** 对工具行按固定 `Alt+Enter`
- **THEN** 仅切换所选行的完整已存参数、结果、成功／错误态；`bashExecution`／`pythonExecution` 用实存命令／代码、输出、退出／错误态，不补 `i`。
- `Shift+Up`／`Shift+Down` 滚详情，键盘／指针换行即收起、回选不恢复；保导航、`Enter` 选择／切换、`Ctrl+O` 循环过滤，不增键位配置。
