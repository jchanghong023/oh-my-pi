# personal-commands

## Purpose

fork 命令、关键词、会话契约及 [TUI 显示差异](#requirement-1-三种显示模式)；不另建调度器。

## Requirements

### Requirement: 原生 `/workspace` 工作区写入提醒

原生 TUI MUST 有会话级隐藏写入提醒；非沙箱／写保护。不增 `approvalMode`、CLI／ACP、审批／分析／拦截；工具／模型／审批／Plan 限制不变。

#### Scenario: 命令与独立会话状态
- **WHEN** `/workspace [消息]`／交付／派生／恢复
- **THEN** 默认关、会话独立持久；补全／状态可辨，与 Plan 共存。无消息只切换不启模型；有消息开启、原生提交一次，保留草稿／附件。
- **AND** 注入：开启时每批真实交付附一份当前提醒（含排队、steer、follow-up）；不改原文／草稿／历史编辑。synthetic follow-up、工具结果、子代理通知、无新输入的重试或压缩不造提交；重建可提醒。
- **AND** 目录：提醒列实际归一化范围：cwd 所属 Git 真根及子目录、`os.tmpdir()`、本会话 `local://` 实际目录。无 Git 明示仅准临时区，不兜底 cwd／home。其他仓库、`additionalDirectories` 不自动准；符号链接／平台归一化非写保护。
- **AND** 越界：可读；改／建／删／移／重命名前说明路径及操作并询问。授权仅对应路径和操作，不重问、不扩权／建程序级授权缓存。涵盖文件工具、Bash、Eval、导入模块、脚本、子进程。
- **AND** 派生：task／eval 和递归代理固定继承创建快照，warm／cold 续跑还原；不随各自 cwd 扩权，另准 OMP 分配的隔离树，各用其会话临时区。父切换仅影响后续输入／新代理；原隔离创建／合并／清理／权限／执行不变。
- **AND** 关闭：持久开关关即停；重建／续聊按持久开关滤旧活动提醒，保留用户历史；不保证抹除已见文本／摘要或不越界。

### Requirement: 原生 `/sketch` 离线画布

原生 TUI MUST 内置自包含 `/sketch`，源码／二进制静态内嵌页面／脚本／样式；无扩展／配置／公网／CDN／外部模型／GUI／ACP／RPC／自动转发。异主机用户 SSH 转发显示端口至 OMP 回环。

#### Scenario: 本地绘图与手动提交
- **WHEN** 打开画布
- **THEN** 画布占满工具栏／状态区外，初始满窗，不强制全屏。手绘、粘贴图片（依赖桌面能力）、标注、颜色／笔刷大小、撤销、清空、调尺寸。按钮、说明、悬浮／无障碍标签、状态、错误中文；保留快捷键名、PNG 等标识。
- **AND** 光标中心滚轮、按钮、100%、适应窗口；空格拖／中键拖／平移模式无笔迹。缩放／平移后绘图／调尺寸坐标准；窗口／视野不改像素和导出尺寸。浏览器 `Enter` 导出整画布 PNG 为真实附件，保留原草稿和附件；不自动发送／启模型。
- **AND** 基线 Firefox 128 默认原生脚本／样式／API；本机 Selenium＋geckodriver、隔离临时 profile 验证，非公司 CentOS／真实桌面认证。

#### Scenario: offline 手动打开画布
- **WHEN** `/sketch` 依据[统一真值](../fork-runtime/spec.md#requirement-安装与运行)处于 `OMP_OFFLINE`
- **THEN** 各平台／Shell 仅显示完整可访问地址；不启浏览器、不调 csh／tcsh `ff`、不读 Shell 启动文件，不需另设跳过变量。非 offline、显式打开链接／文件不变。
- **AND** 仅 Linux offline 成功取址后尝试复制完整 `http://127.0.0.1:<port>/…`（能力路径、查询）；复用 OSC 52、原生剪贴板（X11 selection owner 保活）。不换 LAN、改设置、下载／安装／用外部服务。只报尝试、不称成功／已转发；失败可手抄，不阻断画布／退出。SSH／X11 到 Windows 依赖终端／Exceed；草稿／提交／取消／模型／任务不变。

#### Scenario: 取消、隔离与本地服务清理
- **WHEN** 启动／提交／浏览器或终端 `Escape`／失败／失去归属
- **THEN** 仅绑 `127.0.0.1:0`，随机能力 URL（每次），拒跨源／限载荷。提交完／取消／失败／销毁宿主即关闭废址，取消留草稿。切换／销毁／移焦禁迟到结果串会话／视图（含读 PNG／归一化／插附件）。

### Requirement: `/loopn` 顺序循环提示词

原生 TUI MUST 支持 `/loopn "x1" "x2" "x3"`（≥1 非空提示词）；无次数、间隔、条件、编辑器、暂停恢复；`/loop` 不变。

#### Scenario: 按序发送与回绕
- **WHEN** 启动／运行／停止
- **THEN** 空白须引用；空提示词／未闭引号拒启动。与 `/loop` 互斥，提示先停旧循环、不替换配置。首条立即原生提交，后等前轮及后台结清；末条回首（含单条）。沿用 Loop 调度／`loop.mode`；状态 `LoopN · 当前序号/总数`。
- **AND** `Esc` 原生中断本轮、再次 `/loopn` 或本轮报错即停并清列表／待发；普通输入不恢复，重启重给提示词。

### Requirement: JCH 命令

MUST 复用提示词展开；非法输入无副作用。

#### Scenario: JCH 命令的详细边界
- **WHEN** `/minimal [任务]` 或 `/jchime [故障现象]`
- **THEN** `/minimal` 单发／附任务原生提交最小充分变更和验证提示，不拦截测试／修改。`/jchime` 送内网小模型可执行恢复及受限自主权限，须模型。默认 CentOS 7／GNOME Terminal／SSH X11/Exceed／IBus 1.5.17／`libpinyin`；实时核实，禁旧地址／PID。

|条件|操作边界|
|---|---|
|首选|Bash＋系统 Python 3.6+，本次标准流显式 UTF-8。验 UID／DISPLAY／唯一 daemon／地址文件归属及 PID／引擎可用；请求一次 `ibus restart`，重发现总线，切回并验 `libpinyin`（含切引擎无效的 daemon／XIM 故障）；同 daemon 客户端短断、未提交预编辑或丢失|
|首选失败／症状仍在|按实情重切引擎／对齐调用总线及 X11 环境／重建本显示 IBus；不因脚本退出即停，禁盲重试|
|正常重启无响应|记录原启动参数及必要环境；验 UID／DISPLAY／PID／启动时间，发信号前重验。仅向该正数 PID 发 SIGTERM；退出且无 daemon 接管才原样重建，不自动 SIGKILL|
|进程已退出|仅用户、DISPLAY、X11、现有 D-Bus 归属明确且无重复实例时启动；不另建 D-Bus|
|目标／权限不明|只读|
|停止与报告|安全手段用尽／须手动即报实阻；重验总线及实引擎，不需脚本成功标记。分报服务／输入；子进程环境不证原终端已修；用户在故障窗切换、输入中文确认。非 Windows 本机、Electron 或客户端修复保证|

仅当前用户／DISPLAY；禁 sudo、全局／进程组杀、安装、联网、改持久配置、自动关终端／重启客户端。环境仅调本次／子进程。验提示实送、隔离、回退权限、停止边界；模拟模型／本机 Windows 非公司实机输入证据。

### Requirement: Grill Todo Markdown 任务清单

MUST 内置 `/skill:jch-grill-todo`（仅显式）；复用 `jch-grill-me` 正文，仅改结束语（一致后询问 Todo）及附生成规则；原技能不变。仅自包含 Markdown，无执行器、启动／解析／校验命令、自动实施／开执行会话／新权限。

#### Scenario: 独立确认生成与覆盖
- **WHEN** 就绪问题已解、用户确认一致
- **THEN** 先只读，另询 cwd 固定 `.todo.md` 生成许可；获准重查，存在另询覆盖；拒则不写／合并／改名。结束≠一致／许可，生成≠执行／覆盖；重大决策变化重问有关分支、重获一致与许可。

#### Scenario: 完整 Markdown 清单与文件交付
- **WHEN** 获生成及必要覆盖许可
- **THEN** 写目标、范围／禁区、权限、已定决策、实核材料路径、前置／依赖序／具体改动／最小充分验证／完成标准；不依赖旧聊，无关键待定／占位。
- **AND** 同级 `##` 分组、首 checkbox 紧随组标题；共享背景无 checkbox，说明顺序闭环（组内验证勾完才进下组）。项用普通 `- [ ]`、正文续写、不嵌套／入代码块。组依赖共享前置／前组，项依赖共享前置／已完前项／本项工作；显式跨组依赖，每项有产出、最小验证及可观察完成条件。
- **AND** 按[独立验收](#scenario-统一验收不能阻塞前组勾选)保留验证范围／频率，禁提前勾／弱化／重复验。写后查结构、依赖序、逐项证据、组闭环；前向依赖先重排／拆改。报实路径／检查结果，非实施或验收。

#### Scenario: 统一验收不能阻塞前组勾选
- **WHEN** 勾选依赖测试编写、文档同步及统一公开入口验收
- **THEN** 先拆可独验交付；共用命令／批次、相关性不算合并理由。无独立结果才将不可分的实现／测试／文档／验收合为一项、置能闭环组。后续验收不替前项首次验证；禁跨组环等、跳项、回填。

#### Scenario: 分阶段完成不等于整体验收
- **WHEN** TDD 或后续集成验收
- **THEN** 可分回归（预期红）／修复（相关回归转绿）／最终验收（更广合同），前项不等后项。区分单项／产品验收，预期红非产品通过，不逐项重验。

### Requirement: `/wt` 会话工作树

`/wt` MUST 按目标提交及树状态切换，保留两端未提交内容。

#### Scenario: `/wt` 会话工作树的详细边界
- **WHEN** 指定分支
- **THEN** 目标即当前目录则不迁移、不清理；否则复用已有分支的工作树，或按该分支提交新建。仅分支不存在时从当前 `HEAD` 建分支。新树与源 checkout 根平级（含子目录调用），不受 `worktree.base`／`OMP_WORKTREE_DIR`，不置于 `~/.omp/wt`；路径冲突另选、不覆盖。
- **AND** 不切源分支、不搬未提交内容（含删除），保留两端暂存／未暂存／未跟踪改动；禁自动 stash／提交／reset／clean，忽略 `worktree.cleanSource`。仅新建树走原生 `post-checkout` 与技能／命令刷新；禁钩子约定不变。

### Requirement: LSP code action 应用结果状态

结构化成功 MUST 等于实际应用成功。

#### Scenario: 未指定动作时沿用上游选择
- **WHEN** `code_actions` 的 `apply=true`
- **THEN** `query` 缺／空白沿用上游选择。无候选或不唯一：不应用、明示、`details.success=false` 且工具失败。有效选择且实应用才返动作／结果；取消、选择／应用失败不报成功。

### Requirement: 显式调用无模型网页保存命令

TUI／GUI MUST 内置 `/crawl <URL> [选项]`、`/crawl stop`；授权后无模型／Skill 抓取、转换、保存，直显。缺 URL、未知选项、非法值报错／用法，不抓取或回退模型。

#### Scenario: 保存单个页面
- **WHEN** `/crawl` 获浏览器／写入权限
- **THEN** 默认仅存入口 Markdown；参数见表。

|选项|含义／默认|
|---|---|
|`--recursive`|发现同源导航|
|`--output <目录>`|保存目录；会话 cwd 的 `tmp/`|
|`--concurrency <数量>`|后台标签并发；2|
|`--max-pages <数量>` / `--max-depth <深度>`|递归页数／深度上限；不限|
|`--no-scroll`|仅停逐屏滚动；默认开，无 `--scroll` 开关|
|`--wait <秒数>`|每页初载／开全文后 DOM 就绪起的最短等待；默认 5 秒，0–240 秒（含小数），不逐屏重复|

### Requirement: 复用用户浏览器并保留权限边界

MUST 保留浏览器开关／`OMP_OFFLINE`／授权／目录限制。Browser Relay 复用用户登录态，只用自有后台标签；不抢焦点、导航／关原标签或关浏览器。仅自动操作全文控件，禁业务点击／表单提交／改业务数据。

#### Scenario: 使用已登录浏览器
- **WHEN** 抓取
- **THEN** 禁用、Relay 未连、拒权或目录不合规报因，不绕过／换途径；终止仅释自有标签。

### Requirement: 仅递归发现同源导航页面

MUST 以入口跳转及全文读取后的最终源（协议、主机、端口）限定递归。允许跨源渲染、重定向、全文；跨源子页可存，不发现其站外导航。

#### Scenario: 浏览器原生重定向与深度边界
- **WHEN** 导航／去重／记源
- **THEN** 原生会话／Cookie 等 HTTP／JS 跳转；记最终 URL，保留查询及完整 Hash 路由，仅折叠普通片段。入口深度 0；`--max-depth 1` 仅及直链。

### Requirement: 保存独立且不覆盖的 Markdown 文件

MUST 用现有 HTML→Markdown 逐页保存及记源，重名另取。保留渲染主文档业务区块（含列表、表格，不限选中文章）；相对正文链接可回源，不下载附件；可省导航，非无损备份。

#### Scenario: 保存延迟渲染的企业页面
- **WHEN** 加载含延迟／跨源 API
- **THEN** 跟踪文字、各源文档／Fetch／XHR 至稳定及等足 `--wait`；不等事件流结束。超时不存；按逐屏、全文契约处理。

### Requirement: 默认滚动加载页面内容

启用时 MUST 逐屏下滚入口／子页主文档及视口内嵌套面板，每屏等文字／请求稳定；禁「加载更多」／翻页。

#### Scenario: 滚动追加内容及子页面链接
- **WHEN** 滚动已启用
- **THEN** 加载与滚动共用有界页面预算；按表处理。

|条件|动作|
|---|---|
|无可向下滚的可见区域，末尾尺寸／文字／请求稳定|存主文档现存内容、发现合规链接|
|可滚但下滚稳定后位置／尺寸／地址／文字未变|立即报无进展、释该标签，其他页继续|
|未稳定且预算耗尽|报错、不存该页|
|取消|立即停滚并清理|

虚拟列表非完整归档；不以业务 API、翻页、改状态补齐。

### Requirement: 默认读取明确的全文内容

MUST 识别明确可见「查看全文」「阅读全文」「展开全文」「显示全文」「继续阅读」及明确英文对应（含文字子元素／常见空白／末尾箭头），非「加载更多」／点赞／评论／提交。

#### Scenario: 入口及子页的截断博客
- **WHEN** 入口／子页有全文控件
- **THEN** 优先页内展开；HTTP(S) 链接在自有标签打开（忽略 `target`），稳定后续滚、提取全文、记最终 URL。不追推荐，照常同源递归。不可操作／内容及导航均无变化／下载／非网页协议／表单均报失败，不提交、不下载、不存摘要冒充全文。

### Requirement: 进度、失败和取消

TUI／GUI MUST 显示进度及最终成败、失败 URL／原因；`/crawl stop` 取消本会话抓取。

- `default` 左组无 `vim`、`pr`、`cost`；`git` 与 `context_pct` 间依次 `subagents`、`token_rate`、`cache_hit`，`time_spent` 紧随 `context_pct`。右组空（无 `session_name`）；`subagents` 依配置组序，不强移／重复徽章。
- 两端 Git 段纯文字 `git main · Changes: 5`，无图标或 `*`、`+`、`?`；原三类开关控制暂存、未暂存、未跟踪文件并集，目录逐文件、忽略不计。零改动省计数，无／隐藏分支用 `git Changes: 5`，两项俱无则隐藏。
- `statusLine.contextLine=embedded` 顶边右对齐（如 `ctx 3% · 500K`），不随比例移位；容量及说明弱化、组后两格。未知比例仅容量，真实 >100% 错误色。保用量线、不标预压缩／自动压缩刻度（`annotated` 保留），不影响压缩。路径先依配置上限缩写，放不下状态＋上下文才左截保尾；状态溢出后回补路径至上限，横线填余宽，顶边不足沿原溢出。

### Requirement: 全部工具的显示投影覆盖

当前档位 MUST 覆盖内置／扩展／MCP／设备工具及各阶段；Agent 与 Output 独立选源，Output 不依赖 renderer（含专用、通用、聚合），可用文件回执／诊断。

#### Scenario: 原生与扩展工具均可识别
- **WHEN** 参数流、执行、前后台、终态或迟到更新
- **THEN** 参数流非执行、调用返回非后台成功；动作／预览用已知身份、状态、目标／命令／意图，只有工具名亦显示，不伪造或把陌生工具作读写。wait 动作可用任务快照身份／命令，不用 stdout／stderr。
- Web Search：detailed 折叠／展开皆全文，不传 CLI 限行参；CLI 不变。clean／compact 隐普通搜索及非文件设备包装历史；Output 走通则。

### Requirement: 流式工具摘要的显示稳定性

两端 compact 流式摘要 MUST 每调用单行。沿原规则清理换行、Tab、ANSI、宽字符；扣实左边距再截断，保身份及已有意图／命令，不整体取尾或溢出。

#### Scenario: Eval 标题为非字符串
- **WHEN** 参数空、部分 JSON、错型／缺字段（如 Eval 代码有效但 `title` 非字符串），含 Bash 单独派发已挂载 `eval` 等
- **THEN** 合法字段渐进更新，无崩溃、残留占位或身份／派发序变化；未派发不占运行位，参数非 Output，不改校验或吞错误。

### Requirement: 受限高度下补全选中项可见

ANSI 补全 MUST 优先保光标，菜单随余高及选中项滚动并接受所见。

#### Scenario: 三行或四行终端导航到末尾候选
- **WHEN** ANSI 可用高 3／4 行、至少三个候选，用方向键选末项
- **THEN** 无空间走原非菜单路径，恢复高度保原键位及所见选择。不移输入、不丢正文／光标／草稿／候选、不加设置、不重放或误执行 slash；native 保原受限选择，无不可见选中。

### Requirement: 多行输入的输入法安全布局

`tui.imeSafeCursor` 开且框聚焦用硬件光标时，带侧框非末行的光标若在文本末尾、无选区渲染，MUST 省右框，保左框及文本；否则原框。

#### Scenario: 光标在非末行末尾
- **WHEN** 满足上述条件
- **THEN** 未出现预编辑也生效；末行、其他区域、原文不变。

### Requirement: 紧凑模式显示本轮工具原始 Diff

compact MUST 在正文下、输入上独立显示本会话本轮工具原 Diff，不入历史，不由快照、Git HEAD、参数或历史推算。

#### Scenario: 折叠预览、展开及清理边界
- **WHEN** 本轮有结构化 Diff 或无文本 Diff 的原生删除／重命名
- **THEN** 依完成序保留，不并同文件或抵消还原，排除失败／取消／未执行；无原记录的写入走合格 Output。至下次用户请求／独立运行清空。
- 默认折叠 Edit 卡显示最后可见 Diff、删除单行；窄屏保输入及交互。工具详情键（默认 `Ctrl+O`）依完成序展开，方向／翻页滚动，`Esc` 收起回输入；无可展开项回退 TodoLoop，不展开普通历史或 Output。
- 仅文件及原 Diff，无汇总／统计，保行定位与 detailed 统计，独立于 Output 选源／计时。

#### Scenario: 文件 Diff 与工具输出去重
- **WHEN** 成功结果与所示 Diff 同调用同文件
- **THEN** Output 仅省已表达的成功回执、重复行；保未展示文件、失败、取消、独立警告／诊断；不改结果，去重后空则无 Output。

### Requirement: 固定两行活动区

compact MUST 在输入上固定模型、Agent 两行＋一行留白；ANSI／native 同源，不写历史。

#### Scenario: 区分模型阶段与 Agent 动作
- **WHEN** 当前模型／动作变化或切回 compact
- **THEN** MUST 按下表独立显示；隐思考不隐阶段，空闲模型无旧内容，恢复限本逻辑会话当前事实，无持久化、迟到事件或结束历史混入。

|事实|投影|
|---|---|
|发请求至首帧／思考／正文／工具参数|依次 `Model waiting`／`Model thinking`／`Model replying`／`Model preparing call`|
|已派发动作、并发|派发序首个仍运行＋其余数量；保留最近结束动作时前缀 `Agent: Last`|
|写入、编辑、多文件补丁|确认后路径先于意图；窄屏先舍意图，保可辨文件名及父目录；多目标仅代表路径＋其余数量，目标非改动证据|
|Bash|原命令；仅同会话同调用的可见 Output 信息行已显示命令且有短意图时，改短意图|
|其他工具|真实工具名、目标、查询、操作或已有意图；设备帮助非执行|

- 可见思考追加：按实宽取最后非空排版行；空白追加不抹除、阶段结束即撤；恢复／重建守思考显隐，不摘要或重放。
- 运行的文件名、最近父目录、实时思考用正文亮度；长前缀／意图弱化、结束降级，保明确错误词、突出诊断。
- 运行标签与底栏转圈共用活动窗；转圈／微光启用即动、更新不中断。仅扫活动标签、用上游工作行色；空行、完成、失败、关闭动效、native 减少动态效果不扫光。复用 ANSI 节拍（≤30 FPS，受终端能力和重绘成本限速）及 native 动效；隐藏工作行不改节拍；无加行、轮播或移动槽位。

### Requirement: 紧凑模式的会话等待提示

两端 compact MUST 在 Agent 行提示暂停主会话的实际等待对象，不另占行、不作动作或留快照。

#### Scenario: 会话暂停等待可唤醒的外部工作
- **WHEN** 所看主会话等待后台任务、子代理、消息或排队结果且原流程须提示
- **THEN** 沿原刷新、唤醒／结束即撤；`Esc`／native 停止只结束等待、不取消后台。其他档位、模型阶段、底栏、Output、`wait` 状态不变。

### Requirement: 紧凑显示的维护边界

compact MUST 复用上游布局、渲染、任务订阅和组件；不做平行实现。

#### Scenario: 维护紧凑显示或其验证
- **WHEN** 维护 compact 或其消费者测试
- **THEN** 不恢复工具分段、错误例外、stdout 回退；保 clean／detailed 及共享布局。验收见[最小必要验证](../fork-maintenance/spec.md#requirement-compact-的最小必要验证边界)。

### Requirement: 三档共享转录导航与输入布局

三档 MUST 共用转录布局，不为档位另建导航或归档。

#### Scenario: 正文与表格沿用上游滚动与归档
- **WHEN** 正文／表格超高，底部组件改变、缩放或重绘
- **THEN** 底部按实际可见高度占位；极小先保草稿光标及审批／问答，欢迎区先归档，Todo 不阻稳定行归档。档位投影和收缩不重放、复制、回填或填充；无可见变化不移正文、输入、光标，不擅改独立提示顺序／间距。两端内容一致，不要求同字符串或同重画。

### Requirement: 紧凑模式的最近工具只读输出预览

compact MUST 在活动上方只读显示最近合格 Output；ANSI／native 同预算、选源、期限。

#### Scenario: 最多六行仅含一行信息和有效 Output
- **WHEN** 有合格来源、空间足
- **THEN** ≤6 行：一行真实身份、已知命令／目标、状态（有限 Bash 含原 job ID，多行命令合行截断）＋末 ≤5 行输出。沿原安全清理／测宽；去共同缩进，保相对缩进，实宽排版后仅取含 Unicode 字母／数字的行。
- 信息、日志、动作同正文左距，先扣边距；日志不缩入详情列，极窄至少一列。平面状态底色不盖留白，无框、空行、标题、参数区、Shell 结构、展开提示；活动及留白不计预算。纯文本，无原卡、交互／焦点／键位、滚动、图形（含图片、Mermaid、SVG）、Shell 回放。
- 按实占高，换源不先归零；输出／思考／启动返回走共享布局，空间不足减行、保输入及焦点；resize 只重排，无额外清屏、回填、锚点。

#### Scenario: 最近有输出按派发顺序而非到达顺序选择
- **WHEN** 多调用派发或更新（含参数、图片、空白、纯符号、去重后为空）
- **THEN** MUST 取已获有效文本者中派发最新者；首次合格才可抢占／打开。无效不建、不淘汰、不覆盖已存非空预览或改期限，无合格源为 0 行。旧调用迟到输出／进度／终态不抢占；不并同名调用、不轮播。直接或 Bash 单独调已挂载 `todo`：独立 TODO，不保留／选源；不改活动、执行、结果或其他档位。

|输入|取舍|
|---|---|
|累计、滑动尾窗、重置快照|依原更新契约替换，不累加；保留与展示同资格|
|失败；grep／glob 成功终态|预算内优先各自原诊断、命中行，不造原因|
|wait／read（含聚合）|仅自身真实 Output，可替换 Bash；任务快照非 Bash stdout，不追踪旧命令、搬组件或混调用|
|write `out://` 等|走原回复路由，不取正文／参数伪作 Output、不重复回复|
|无真实文本|不以参数、元数据、工具名或思考伪造进度|

#### Scenario: 运行期间保留且停止后计时
- **WHEN** 来源未达真实整体终态，或底栏仍运行
- **THEN** MUST 保留；期限＝max(底栏会话停止时刻, 整体成功／失败／取消终态接收时刻)＋3 秒。输出、resize、切视图／档位、全屏、重建、未绘制均不续期／暂停，空闲可未见即到期。

|边界|必须行为|
|---|---|
|有限异步 Bash 每秒输出，共 25 秒，已返回且未被抢占|全程反映已收文本，不需历史卡、模型读 `proc://`、wait、反复查询；调用耗时在真实返回时冻结，后台独立|
|启动返回 running／终态早到|启动返回、loop／主 Agent 结束非整体终态；迟到 running 不覆盖终态或改期限|
|服务／交互 PTY|按启动调用自身终态，不等退出、不冒充进程终态；不增订阅、复制或监控|
|task 多异步及阻塞子任务|等权威聚合及阻塞结束，不只 primary job；末队列项取消无输出也据结算终止，不常驻、轮询或推定成功|
|新源替换、关闭|合格新源可提前替换；关窗释放占高、无占位，不影响新源、他会话、活动、TODO 或任务取消／投递；截断不损全文、工件、诊断或入口|
|关较新源 B 后，旧源 A 仍输出或 B 迟到|归零，不回退 A、不重开 B；空闲只允许更晚派发首获有效文本者重开，重新运行按通则用本会话已有 Output|

- 切会话／代理／档位按本会话派发事实、资格及原期限恢复；不从结束历史补／重开，不恢复空闲到期项。同名工具／call ID、快照、迟到输出、关窗按逻辑会话隔离；不跟踪未查看会话，不触发卡片副作用。

### Requirement: `/tree` 工具意图与所选行内详情

ANSI／native `/tree` 的 `toolResult` MUST 将本调用非空白字符串 `i` 前置于原工具名／参数摘要，支持搜索；用户／助手行不变。

#### Scenario: 工具结果行使用自身调用意图
- **WHEN** 无有效 `i`
- **THEN** 保原摘要，不借其他调用或结果正文。

#### Scenario: 仅展开当前所选工具行
- **WHEN** 对工具行按固定 `Alt+Enter`
- **THEN** 仅切换所选行的完整已存参数、结果、成功／错误态；`bashExecution`／`pythonExecution` 用实存命令／代码、输出、退出／错误态，不补 `i`。
- `Shift+Up`／`Shift+Down` 滚详情，键盘／指针换行即收起、回选不恢复；保导航、`Enter` 选择／切换、`Ctrl+O` 循环过滤，不增键位配置。
