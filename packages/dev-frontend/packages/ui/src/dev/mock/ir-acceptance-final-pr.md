## PR 正文

完成当前 IR 的整体验收，提交本轮必要的实现修复、测试及一致性更新，并将 Change 移入 OpenSpec 原生归档目录；无修复时仅提交归档。

归档仅移动 Change，不重复同步已随各 SR PR 合入的规格。保留 worktree、分支及历史，不自动清理。

## 验收依据

以右侧验收报告记录的默认分支基点及最终候选为准。合并前默认分支变化时重新核对影响并补验；失败或未执行项如实披露。

## 人工操作

1. AI 在明确授权后提交、推送分支并提供标题和正文（本原型不执行）。
2. 人工创建、评审并合并 PR，然后告知平台。
3. 平台核验默认分支上的最终候选成果与归档后，IR 才完成，释放仓库占用。

仅登记 PR 链接不代表合并；页面核验仅为演示，不连接 PR 平台或 Git。
