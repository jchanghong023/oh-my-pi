**业务需求 Agent · 需求提案讨论（样例）**

本提案以 IR 为讨论单位，SR 只在右侧阅读自身规格，不建立独立会话。当前版本由 A／B／C 三个不同模型独立只读评审，第四个综合评审 Agent 汇总意见；四份同版报告完整后，人决定“通过，进入技术方案”或“返回业务补充”。需求更新后须重评，不要求先交接或独占接手。

先补齐目标、使用场景、范围与边界，再明确下属 SR 的输入、输出和验收条件。左侧只列 IR，可在右侧材料选择器切换各 SR 的规格，讨论和修改仍回到所属 IR。

- IR 说明为什么做、为谁做，以及本次不包含哪些内容。
- 每个 SR 对应一项明确的系统要求，并提供可检查的验收条件。
- 草稿和需求评审不要求已有方案；人工通过当前版本评审后进入方案。方案完成并逐文件确认当前 IR、全部 SR 和方案后，平台才创建分支并提交推送，人到 Git 网页处理 PR。

本页为内存演示，尚未接入真实评审、PR 或模型调用。
