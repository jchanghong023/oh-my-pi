**业务需求 Agent · 需求提案讨论（样例）**

本提案在业务需求阶段的 IR“需求讨论”和全部 SR 共用此业务需求会话，切换 SR 仅定位材料；消息与未发送输入保持不变。当前版本先经过业务需求评审 Agent 检查；未通过或材料变化时先补充并重评。通过后点击“提交给开发”，由开发人员明确接手，再使用方案 Agent 完善方案。

先补齐目标、使用场景、范围与边界，再明确下属 SR 的输入、输出和验收条件。左侧 IR 展开后可查看各个 SR，点击讨论按钮可回到整组提案。

- IR 说明为什么做、为谁做，以及本次不包含哪些内容。
- 每个 SR 对应一项明确的系统要求，并提供可检查的验收条件。
- 草稿和业务需求评审不要求已有方案；交给开发前必须通过当前版本业务评审，提交 PR 前还须由开发人员完成并确认方案。

本页为内存演示，尚未接入真实评审、PR 或模型调用。
