# Changelog

## [Unreleased]

### Changed

- Skill 设计改为桌面左右工作区，补充讨论与文件预览按标签切换；新增缺项定位、四类示例、逐字段建议、旧预览变更对照，以及保存项目／路径／名称冲突提示。

- Dev 的界面设计与验收仅面向桌面浏览器，不再要求手机适配；WebGUI 的手机范围不变，本轮不修改 WebGUI。

- Dev 导航改为点击 IR 展开 SR、点击 SR 进入带阶段信息的聊天布局，需求讨论沿用按钮操作；搜索采用 WebGUI 弹窗，筛选与列表展开复用原动效，未开始及已完成 SR 保留只读聊天布局。

### Fixed

- 原型巡查补齐辅助对话演示响应，收起顶部次要流程信息，改善 Markdown 材料阅读、IR／草稿统计、Skill 预览定位与补充字段间距。

### Added

- 新增独立“Skill 设计”原型：结构化字段、复用原聊天窗格的补充讨论、文件与待试用例预览及项目内存保存，不改造原技能页或执行真实模型／文件操作。

- Dev 左侧原型将项目与其 Release 相邻联动选择，提供统一新建菜单、当前开发入口及需求搜索／筛选；项目登记归个人配置，Release 归各项目 Git，协作入口位于会话顶部。

- Dev 设置原型支持 5 个核心 Agent 的个人模型配置及追加系统提示词编辑，演示跨项目共用、保存／取消及键盘保存；尚未连接真实 OMP 配置读写。

- 支持使用 Bun 和浏览器独立预览当前 Dev 前端原型，无需 OMP、Rust 或模型凭据。
- 各 Dev 模块提供随源码交付的样例数据和本地演示交互；此为临时 UI/UX 评审阶段，确认后继续真实后端对接与最终验收。
