# C/C++ 测试报告规则

## 覆盖率数据获取

### 使用gcov

```bash
# 检查gcda文件
find . -name "*.gcda" | grep {TARGET_SOURCE_FILE}
# 生成覆盖率报告
mkdir -p /tmp/ut-cpp/gcov_output && cd /tmp/ut-cpp/gcov_output
gcov {TARGET_GCDA_PATH} > /dev/null 2>&1
# 提取覆盖率统计
grep "#####:" xxx.cpp.gcov  # 未执行行
```

### gcov标记含义

| 标记 | 含义 |
|------|------|
| `数字:` | 已执行次数 |
| `#####:` | 未执行 |
| `-:` | 不可执行 |
| `=====` | 特殊标记 |

### 覆盖率指标

- 行覆盖率（主要指标）
- 分支覆盖率（如可用）
- 函数覆盖率

**目标**：行覆盖率 ≥ 90%

## 测试质量评估与异常覆盖检测

详见 [测试质量评估与异常覆盖检测](./report-checks.md)，包含：
- 结构评估5项（测试套组织/Fixture/辅助函数/include组织/extern "C"）
- 命名规范检查5项
- 断言质量检查9项
- 字段级校验检查6类
- 异常覆盖检测（C++异常3维度 + C错误处理3维度 + catch块逻辑5类 + 检查清单4项）

## 附加检查汇总格式

| 检查项 | 状态 | 发现 | 修复总结 |
|--------|------|------|----------|
| 异常覆盖检测 | ✅/🔧/❌/⚠️ | catch块/错误处理覆盖关键发现 | 修复内容或无需修复 |
| 断言有效性检查 | ✅/❌/⚠️ | 伪断言/缺失断言/仅存在性关键发现 | 修复内容或待修复 |
| 命名规范检查 | ✅/🔧/❌/⚠️ | 命名/注释/文件命名关键发现 | 修复内容或无需修复 |

状态说明：
- ✅ 通过：检查项全部合规
- 🔧 已修复：发现问题并已修复
- ❌ 发现问题：发现问题待修复
- ⚠️ 无数据：检查结果不可用
