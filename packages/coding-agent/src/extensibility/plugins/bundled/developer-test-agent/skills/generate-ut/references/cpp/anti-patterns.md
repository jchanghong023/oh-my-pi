# 反模式禁令

## 反模式禁令完整列表（21条）

### Mock误用禁令（10条）
1. 禁止循环Mock：Mock目标必须是被测函数实际调用的外部函数。禁止在测试文件中创建wrapper函数然后Mock它们
2. 禁止Mock被测类/被测函数本身
3. 禁止Mock标准库函数：C标准库（string.h/stdlib.h/stdio.h/math.h）和C++标准库（string/vector/map/optional/chrono/memory等）
4. 禁止Mock私有成员函数
5. 禁止Mock libc核心函数（Windows/MinGW）：禁止Mock malloc/free/printf——gtest内部也调用它们会导致无限递归。改用替代策略
6. 禁止无意义Mock：如果被测函数不调用外部依赖，不需要引入任何Mock框架
7. 禁止死代码Mock：禁止编写平台#ifdef保护的Mock测试但实际在当前平台永不执行
8. 禁止static函数打桩：将其逻辑作为被测函数一部分，禁止Mock static函数
9. 禁止Mock遍历函数：禁止Mock遍历操作函数（HasNext/FetchNext/GetNext/Next等），应该Mock数据提供函数并在输出参数中填充测试数据
10. 禁止Mock单例获取：禁止Mock单例获取函数（GetInstance/sInstance/GetSingleton等），应该直接Mock实例方法

### 断言误用禁令（3条）
11. 禁止间接断言耦合：验证操作结果时使用最直接的验证方法，禁止使用带哨兵值的复杂查询方法
12. 禁止仅NoThrow断言：void方法必须验证可观测状态变更，禁止仅使用EXPECT_NO_THROW。如果状态确实不可观测，命名必须使用_NoThrow后缀并在注释中说明
13. 禁止GTEST_SKIP：用例没有任何有效信息。保留用例代码，使用宏定义禁用

### 编码误用禁令（4条）
14. 禁止硬编码二进制测试数据：优先使用计算辅助函数（如CRC计算器、帧构建器）而非硬编码字节数组
15. 禁止#define private public作为首选方案：优先通过公共接口测试。仅当公共接口不足以验证期望行为时使用#define private public，且必须遵守include顺序规则。如果导致崩溃，立即移除并改用公共接口
16. 禁止重写被测类：禁止重写一个完整的被测试类作为测试对象。必须使用真实的业务代码进行测试
17. 禁止随意指针转换：禁止使用reinterpret_cast<ClassName*>(0x1)将随意值转换为指针，应使用构造函数构造对象

### 代码修改禁令（4条）
18. 禁止任务-代码错配忽略：如果任务描述的函数在源码中不存在，必须在输出中标注错配，测试实际存在的最接近函数
19. 禁止修改第三方库：不修改libs/、vendor/下的任何文件
20. 禁止static全局变量赋值：只能使用初始值，禁止在测试中修改被测模块的static全局变量
21. 禁止测试文件全局变量定义：禁止在测试用例文件中定义全局变量，只能通过extern声明

## 禁止编码方式（5种）

| 模式 | 禁止写法 | 原因 | 正确写法 |
|------|----------|------|----------|
| 重写被测类 | 重写完整被测类作为测试对象 | 测试结果无效 | 使用真实业务代码 |
| 指针转换 | `reinterpret_cast<ClassName*>(0x1)` | 随意地址可能崩溃 | 使用构造函数构造对象 |
| 硬编码字节数组 | 硬编码CRC值 | 算法错误需改所有用例 | 使用计算辅助函数 |
| 测试文件全局变量 | 在测试文件中定义全局变量 | 状态污染 | 通过extern声明 |
| 修改static全局变量 | 在测试中修改被测模块static变量 | 破坏隔离 | 只使用初始值 |
