# Go 反模式禁令

## Mock误用禁令

1. 禁止循环Mock：Mock目标必须是被测函数实际调用的外部函数。禁止在测试文件中创建wrapper函数然后Mock它们
2. 禁止Mock被测函数本身
3. 禁止Mock标准库函数：Go标准库已充分测试且稳定可靠，Mock无意义且易造成测试失真
4. 禁止无意义Mock：如果被测函数不调用外部依赖，不需要引入任何Mock方案
5. 禁止Mock遍历函数：禁止Mock遍历操作函数（HasNext/Next等），应该Mock数据提供函数
6. 禁止用t.Skip掩盖问题：应使用mock/fake替代t.Skip，t.Skip掩盖单元测试中缺失的隔离

## 断言误用禁令

7. 禁止间接断言耦合：验证操作结果时使用最直接的验证方法，禁止使用带哨兵值的复杂查询方法
8. 禁止仅NoThrow断言：void函数必须验证可观测状态变更（全局变量/类成员/输出参数）
9. 禁止Skip用例：用例没有任何有效信息。保留用例代码并注明禁用原因

## 编码误用禁令

10. 禁止硬编码二进制测试数据：优先使用计算辅助函数而非硬编码字节数组
11. 禁止重写被测函数：禁止重写一个完整的被测函数作为测试对象，必须使用真实的业务代码进行测试

## 代码修改禁令

12. 禁止任务-代码错配忽略：如果任务描述的函数在源码中不存在，必须在输出中标注错配，测试实际存在的最接近函数
13. 禁止修改第三方库：不修改vendor/下的任何文件
14. 禁止修改生产代码：不改变可见性、签名、实现，使用gomonkey/字段注入替代
