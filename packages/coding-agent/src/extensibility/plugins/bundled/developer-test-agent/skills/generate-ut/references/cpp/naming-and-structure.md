# 命名规范与代码组织结构

## 命名规范

- **测试套（Fixture类）**：Test + 被测对象名，大驼峰风格
- **测试用例**：大驼峰风格，用例名中应包含关键输入和输出信息
- **测试用例名称不使用中文**
- 使用大驼峰而非小写下划线（gtest用下划线拼接套件名和用例名，下划线命名可能冲突）
- 测试套+测试用例名可连贯阅读，见名知意

## 文件命名规范

- 测试用例文件：被测文件/功能/模块名 + "_test" 后缀，.cpp扩展名（即使测.c文件）
- Mock文件：被mock对象名 + "_mock" 后缀
- Stub文件：被stub对象名 + "_stub" 前缀
