# Go 异常覆盖检测

## 异常覆盖检测

### Go错误处理（非异常）

Go使用error值而非异常，对应的"异常覆盖"为错误处理路径覆盖：

| 检查维度 | 说明 |
|----------|------|
| 错误检查分支 | `if err != nil` — Mock依赖返回错误 |
| 错误类型断言 | `if errors.Is(err, X)` — 构造类型化错误 |
| 错误字符串匹配 | `if strings.Contains(err.Error(), "msg")` — 构造包含特定字符串的错误 |
| 错误包装 | `fmt.Errorf("...: %w", err)` — 验证错误链 |
| defer错误处理 | `defer func() { if r := recover(); r != nil {...} }` — 触发panic验证recover |
| 错误聚合 | `multierror.Append()` — 构造多个错误验证聚合 |

### 错误处理逻辑覆盖

| 逻辑类型 | 覆盖要点 |
|----------|----------|
| 日志记录 | 验证logger被调用 |
| 错误转换 | 验证新错误类型和消息 |
| fallback返回 | 验证返回默认值 |
| 资源清理 | 验证defer close被调用 |
| 状态重置 | 验证状态被重置 |
| 重试逻辑 | 验证重试次数 |
| 错误聚合 | 验证聚合错误包含所有子错误 |
